# Golden Dragon

Golden Dragon es un demo personal de frontend para el concepto de un sitio web de un restaurante de comida china. Lo creé como proyecto web independiente para explorar una página de restaurante con una presentación visual cuidada e interacciones.

## Funcionalidades

- Navegación adaptable y menú para dispositivos móviles
- Secciones de presentación, menú, testimonios, contacto y reservaciones
- Tarjetas del menú generadas con datos de JavaScript y filtros por categoría
- Animaciones al desplazarse, contadores animados y carrusel de testimonios
- Interacción de muestra para el formulario de reservación

## Tecnologías

- HTML
- CSS
- JavaScript sin frameworks

## Cómo ejecutarlo

No requiere un proceso de compilación. Clona el repositorio y abre `index.html` en un navegador. Algunas imágenes, fuentes y el mapa se cargan desde servicios externos, por lo que necesitas conexión a internet para verlos.

## Alcance del demo

Este es un concepto personal, no un sitio web de un restaurante en funcionamiento. Los datos del restaurante, el menú, los testimonios, la dirección y el teléfono son ilustrativos. El formulario solo muestra una confirmación en la interfaz: no envía ni guarda reservaciones.

## Estructura del proyecto

- `index.html` — secciones y contenido de la página
- `style.css` — diseño visual y estilos adaptables
- `script.js` — datos del menú y funciones interactivas
